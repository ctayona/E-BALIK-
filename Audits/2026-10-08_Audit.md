### Findings from the connectivity audit (before any change)
- **A guard could not release items.** The live `admin_update_claim_status` database function only admitted `admin` and `super_admin` (verified read-only on the live database), so a guard who scanned a Handover PIN was refused. Only admins could release.
- **The lost report was only closed when an administrator had confirmed an AI match** for it. A claim carries no link to a lost report, so a normal claim and release left the owner's lost report "missing".
- **Guards could be assigned only by super admins, through a small icon** (the database function required `super_admin`).
- Users could hard-delete their own found report at any time, which would delete the claims on it and the custody record.
- The admin Dashboard already had the PIN screen for admins, but nothing in the menu said so.
